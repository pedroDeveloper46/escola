📚 Sistema de Matrículas – Escola
🎯 Objetivo do Projeto
Este projeto foi criado com o intuito de refrescar conceitos de back-end e praticar integração entre banco de dados e aplicação. A ideia é simular um sistema acadêmico simples, permitindo gerenciar alunos, cursos e matrículas, além de gerar relatórios úteis para administração escolar.

⚙️ Tecnologias Utilizadas
Java com arquitetura MVC

JDBC para integração com banco de dados

SQL para consultas e relatórios

Hash de senha para segurança no cadastro de alunos

Arquivo de configuração (db.properties) para conexão com o banco

🚀 Features Implementadas
Cadastro de alunos

Login único por aluno

Senhas armazenadas com hash

Gerenciamento de cursos

Criação e listagem de cursos

Associação de cursos às matrículas

Sistema de matrículas

Registro de matrícula vinculando aluno e curso

Tranca/cancelamento de matrícula


Consultas SQL com JOIN

Listagem geral de matrículas com curso e aluno

Cursos de um aluno específico

Histórico de matrículas de um aluno

Detalhamento de matrícula específica

Relatório completo de alunos e cursos

Relatórios estatísticos

Contagem de alunos por curso

Ranking Top 3 cursos mais visados
